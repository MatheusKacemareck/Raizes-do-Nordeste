# Raizes-do-Nordeste
Projeto de front-end para rede de restaurantes e lanchonetes  de comida nordestina. Protótipo acadêmico UNINTER

## Funcionalidades
- **Cardápio dinâmico e Carrinho de Compras:** Permite visualização de itens e unidades simulados no navegador, também permite adição, alteração e remoção de itens do carrinho.
- **Simulação Autenticada:** Utlização de mock data para acessos de testes de avaliações, também permitindo cadastro manual.
- **Processamento de Pagamento:** Simulação de pagamento(Cartão de Crédito, Débito e Pix).
- **Acompanhamento de Status do Pedido:** visualização clara no status do pedido (Recebido → Em preparo → Pronto para retirada/Saiu para entrega → Concluído).
- **Programa de Fidelidade:** Sistema de acúmulo de pontos e resgate de produtos.
- **Conformidade com LGPD:** Política de Privacidade e Termos de Uso.

## Tecnologias Utilizadas
- **HTML5:** Semântica e estruturação.
- **CSS3:** Estilização, responsividade e animações
- **Javascript:** Lógica, validações e localstorage

## Recursos visuais
- Fontes **DM Sans** e **Playfair Display** foram utilizados no projeto, através do [Google Fonts](https://fonts.google.com/)
- Ícones vetoriais utlizaram [Font Awesome](https://fontawesome.com/)
- Imagens e Logo do projeto gerados com inteligência artificial.

## Como Executar
1. Acesse a opção **Entrar**.
2. Crie uma nova conta ou acesse a opção **"Acesso Teste"** no canto inferior direito da tela de login/cadastro.
2.1. Em caso de acesso teste, escolher um dos perfis antes seguir simulação de uso do site.
3. Faça a navegação do site com liberdade para simular seleção de unidades, cardápio, carrinho e pagamento.
